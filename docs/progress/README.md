# Dated research reports

These files are dated snapshots copied from the working research tree. Each report records the scope and state at its own date. Read [STATUS.md](../../STATUS.md) for the current archive-level statement; a historical process report is not evidence that a run is still active or that a later proof obligation has been completed.

The reports include leading-form factor audits, classical degree-criterion and Shastri-scope reviews, F2 band and terminal-chain derivations, and the later root/divisor reductions. Their filename prefixes are retained to preserve provenance and make updates traceable.
